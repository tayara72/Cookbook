Privacy Policy

Effective date: May 23, 2026

This Privacy Policy explains how Cooksie handles information when you save, organize, import, back up, and restore recipes.

Information Stored in Cooksie

Cooksie allows you to create and save recipes, including recipe names, ingredients, instructions, selected photos, and favorite selections.

Saved recipes and photos added manually or through editing are stored locally on your device as part of your recipe collection.

Recipe Import Features

Cooksie offers several ways to import recipe content. The information processed depends on the feature you choose to use.

  • Paste Text: Recipe text you paste into the app is sent to OpenAI for processing so that Cooksie can identify and organize recipe details such as titles, ingredients, and instructions.
  • Import from URL: When you provide a recipe webpage URL, Cooksie requests the webpage content from that website. If local parsing is not sufficient to extract the recipe, extracted webpage text may be sent to OpenAI for recipe processing.
  • Choose Photo: Photos selected for recipe import are processed on-device using Apple's Vision text-recognition technology. The photo itself is not sent to OpenAI. Text recognized from the photo is sent to OpenAI for recipe processing.
  • Manual Entry: Recipes created manually do not require AI processing as part of normal app operation.

External Services

Cooksie uses or may interact with the following external services when you choose certain features:

  • OpenAI API: Receives pasted recipe text, extracted webpage text when AI parsing is needed, and OCR-extracted text from selected recipe photos in order to structure recipe content.
  • Recipe Website Hosts: Receive a webpage request when you import a recipe from a URL.
  • Remote Image Hosts: May receive a request when Cooksie displays an externally hosted image associated with an imported recipe.
  • iCloud Drive: Receives a recipe backup file only if you choose to export a backup and select iCloud Drive as its location.

How Information Is Used

Recipe content submitted for import is used to provide the requested app functionality, including identifying recipe titles, ingredients, and instructions and presenting them in an organized format.

Cooksie does not use recipe content for advertising or analytics. The app does not include advertising SDKs or analytics SDKs.

OpenAI Data Handling

Cooksie sends certain recipe text to the OpenAI API only when needed for an import feature you choose to use.

According to OpenAI's API data controls, data submitted through the API is not used to train or improve OpenAI models by default unless the API organization explicitly opts in. OpenAI may retain API inputs and outputs for a limited period for abuse monitoring and service operation, subject to OpenAI's applicable data controls and retention policies.

Photos

When you import a recipe from a photo, the image is analyzed on your device using Apple Vision OCR to recognize text. The original selected image is not sent to OpenAI by Cooksie's normal import process.

Photos that you add to recipes manually or while editing are compressed and stored locally in the app's recipe data.

Backups and iCloud Drive

Cooksie allows you to export your recipe collection as a JSON backup file. You choose whether to create a backup and where to save it through the iOS Files sheet. If you select iCloud Drive, the backup file is stored in your iCloud Drive account and is subject to Apple's applicable policies and your iCloud settings.

Cooksie can restore recipe data only when you choose a backup file for restoration.

Retention and Deletion

Recipes and locally stored recipe photos remain on your device until you delete them from the app or remove the app and its locally stored data.

Exported backup files remain in the storage location you selected until you delete them there.

Content sent to external services is handled according to the retention practices of those services. OpenAI API content may be retained for abuse monitoring and service operation as described in OpenAI's API data controls.

Your Choices

  • You may create recipes manually without using AI-assisted import.
  • You may choose whether to import content from text, URLs, or photos.
  • You may delete saved recipes from Cooksie.
  • You control whether and where you export backup files.
  • You may delete exported backup files from the storage location where you saved them.

Children's Privacy

Cooksie is not designed to collect personal information from children. The app is intended for organizing recipe content provided by the user.

Changes to This Policy

This Privacy Policy may be updated if Cooksie's features or data practices change. Any updated version will show a revised effective date.
